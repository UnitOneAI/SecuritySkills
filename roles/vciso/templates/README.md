# vCISO Templates

These templates extract governance deliverables from `SKILL.md` into reusable
files that can be populated, reviewed, and validated.

- `security-program-maturity-summary.md`
- `ninety-day-remediation-roadmap.md`
- `board-ready-security-posture-report.md`
- `risk-register.csv`

Each template includes source versions, evidence window, owner, and residual
risk fields so outputs remain auditable.

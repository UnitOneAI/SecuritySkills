# vCISO Governance Sources

Record these source versions in every vCISO engagement output.

| Source | Required metadata | Used for |
| --- | --- | --- |
| NIST CSF 2.0 | Profile, function/category scope, assessment date | Maturity assessment and board reporting |
| AICPA Trust Services Criteria | Criteria scope, audit period, source date | SOC 2 readiness |
| ISO/IEC 27001:2022 + Amd 1:2024 | Edition, amendment, transition assumptions | ISMS and compliance mapping |
| CIS Controls v8 | Implementation group, safeguards version | Technical control roadmap |
| OWASP LLM Top 10 2025 | Taxonomy version and app scope | AI/LLM program review |
| OWASP Agentic AI Top 10 | Taxonomy version and agent scope | Agentic AI governance |
| FAIR | Calibration assumptions and ranges | Quantitative risk discussion |

If evidence is missing, stale, or outside the assessment window, mark the item
`Not Evaluable` and assign an evidence owner.

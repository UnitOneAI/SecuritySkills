# AppSec Engineer Templates

These templates are reusable scaffolds for the AppSec Engineer role bundle.
They make engagement output auditable instead of relying only on inline prose
inside `SKILL.md`.

Use these files when producing deliverables:

- `application-threat-model.md`
- `pr-security-review.md`
- `api-security-assessment.md`
- `ai-feature-security-assessment.md`

Each template requires framework source versions, evidence confidence, and
follow-up ownership for conditional or failed items.
